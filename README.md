#  Customer Segmentation & Spending Analysis

##  Project Background

I worked on this project to understand a simple but important business question — *are all customers really the same?*

Using customer income and spending data, I explored how different types of customers behave and whether they can be grouped into meaningful segments. The idea was to move beyond raw data and actually uncover patterns that could help in decision-making.

---

##  What I Did

* Cleaned and prepared the dataset for analysis
* Explored relationships between income and spending
* Identified different customer groups based on their behavior
* Built visualizations to clearly highlight these patterns
* Created a Power BI dashboard to present the insights in a more interactive way

---

##  Key Insights

* Customers naturally fall into distinct groups based on income and spending habits
* High-income customers don’t always translate to high spending
* Certain segments clearly stand out as potential high-value targets
* These insights can help businesses focus their marketing efforts more effectively

---

##  Tools Used

* Python (Pandas, Matplotlib, Seaborn)
* Jupyter Notebook
* Power BI
